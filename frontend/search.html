Position & filters

What to search for, and how to narrow it down

Position/seniority are used as the search query for Google Jobs (needs SERPAPI_KEY), and as a title filter applied to every Greenhouse/Lever/watchlist/site result -- seniority via keyword matching (e.g. "senior", "staff", "junior"), so it's a heuristic, not exact. Max time since posted only applies where a real posted date is available (Greenhouse, Lever, Google Jobs) -- sites searched with the best-effort scraper below have no reliable date, so they're never excluded by this filter. Max results per site caps how many raw results are pulled from each individual board/site before filtering, so it's mainly useful for large boards or to keep scraping polite. Saved to .env — both the button below and the scheduler's automatic 8am run use whatever's saved here.

Wuzzuf and Bayt.com are pre-added below by default (both verified to return real results with a plain, unauthenticated request) — remove either one if you don't want it searched. LinkedIn and Indeed were tested too and block that outright, so they're not included and won't work if you add them manually either. For those two, the search query is rebuilt from Position each run, so they're skipped for a run where Position is blank. Add specific companies (Greenhouse/Lever boards) or any other site here too — Greenhouse/Lever URLs are detected automatically and searched via their public APIs, same as the .env-configured boards. Any other URL is searched with a best-effort scraper — it looks for same-site links that look job-related, so results can be noisier and depend on the site's structure. Respect each site's Terms of Service before adding it.
