infoHow these filters are applied expand_more

Position/seniority are the search query for Google Jobs (needs SERPAPI_KEY) and a title filter on every Greenhouse/Lever/watchlist/site result; seniority is keyword-matched ("senior", "staff", "junior"), so both are heuristics, not exact.

Freshness only applies where a real posted date exists (Greenhouse, Lever, Google Jobs) — sites read by the best-effort scraper have no reliable date and are never excluded by it. Max results caps raw results pulled from each board before filtering. Saved to .env.

shieldWhich sites work, and how they're searched expand_more

Wuzzuf and Bayt.com are pre-added (both return real results to a plain, unauthenticated request) — remove either if you don't want it. LinkedIn and Indeed block that outright, so they're not included and won't work if added. For those boards the query is rebuilt from Position each run, so they're skipped when Position is blank.

Greenhouse/Lever URLs are detected automatically and searched via their public APIs. Any other URL uses a best-effort scraper that follows job-looking same-site links, so results can be noisier. Respect each site's Terms of Service before adding it.
